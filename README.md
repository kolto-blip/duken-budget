# 🛒 Дүкен / Бюджет

Командная веб-игра для школьников: математика + русский/английский язык.

Команды получают бюджет, покупают товары по заданию, сами считают итог и сдачу,
проверяют ответ кнопкой **«Тексеру»**, а затем составляют диалог «продавец — покупатель».

- Уровень 1 — сложение и вычитание
- Уровень 2 — умножение (цена × количество)
- Уровень 3 — скидки −10% и −25%

Один файл `index.html`, работает офлайн, на телефоне и проекторе.
